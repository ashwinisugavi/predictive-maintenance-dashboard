# Predictive Maintenance Analytics Dashboard

## Overview

This project predicts equipment failures using
machine learning algorithms and anomaly detection.

## Features

- Root Cause Analysis
- Failure Prediction
- Model Comparison
- Hyperparameter Tuning
- Anomaly Detection
- Real-Time Monitoring

## Models

- Linear Regression
- KNN Regressor
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation Metrics

- MSE
- RMSE
- R² Score
- Cross Validation Score

## Deployment

streamlit run app.py
